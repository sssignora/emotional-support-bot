# Чат-бот для эмоциональной поддержки

Чат-бот для ВКонтакте с интеграцией GigaChat. Позволяет отслеживать эмоциональное состояние и вести поддерживающий диалог.

## Функционал
- Запись настроения и оценка по шкале 1–10
- Просмотр статистики (последние 10 записей)
- Свободный диалог с GigaChat (учёт контекста)
- Автоматическое предложение телефонов доверия при критическом состоянии

## Технологии
- Python 3.x
- VK API (библиотека vk_api)
- GigaChat API
- JSON для хранения данных

## Установка и запуск
1. Склонируйте репозиторий
2. Установите зависимости: `pip install vk_api gigachat`
3. Вставьте ваши токены VK и GigaChat
4. Запустите: `python bot.py`
